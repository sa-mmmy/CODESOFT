Un ensemble de projets de machine learning et data science axés sur des problématiques réelles telles que la détection de fraude, la prédiction du churn client et la classification de genres de films.
Ce dépôt contient plusieurs notebooks Jupyter illustrant différentes approches de modélisation et d’analyse de données.

Projets inclus : 

📌 Détection de fraude par carte bancaire

Fichier : credit card fraud detection.ipynb

Identification des transactions frauduleuses à l’aide de modèles de machine learning

Gestion des jeux de données déséquilibrés

Prétraitement des données, entraînement des modèles et évaluation des performances

📌 Prédiction du churn client

Fichier : customer-churn (1).ipynb

Prédiction du départ des clients à partir de données comportementales et démographiques

Analyse exploratoire des données (EDA)

Feature engineering et comparaison de plusieurs modèles

📌 Classification de genres de films

Fichier : movie-genre-classification.ipynb

Classification des genres de films à partir de données textuelles ou de métadonnées

Utilisation de techniques de Traitement du Langage Naturel (NLP)

Modèles de classification supervisée

Installation et utilisation

Cloner le dépôt :

git clone https://github.com/votre-utilisateur/sa-mmmy.git
cd sa-mmmy


Installer les dépendances :

pip install pandas numpy scikit-learn matplotlib seaborn


Lancer Jupyter Notebook :

jupyter notebook


Ouvrir le notebook souhaité et exécuter les cellules dans l’ordre.
